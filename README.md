# 📝 تطبيق قائمة المهام | To-Do List App

تطبيق ويب حديث وسهل الاستخدام لإدارة المهام اليومية مع ميزة حفظ البيانات محلياً.

## ✨ الميزات

### 🎯 الميزات الأساسية
- ✅ **إضافة المهام** - أضف مهام جديدة بسهولة
- ❌ **حذف المهام** - احذف المهام غير المرغوبة
- ✏️ **تعديل المهام** - عدّل نص المهام الموجودة
- ✔️ **تحديد المهام المكتملة** - ضع علامة على المهام المنجزة

### 🔍 تصفية وبحث
- 📊 **تصفية ذكية** - عرض جميع الم��ام أو المهام الجارية أو المكتملة
- 🔎 **بحث فوري** - ابحث عن المهام بسهولة

### 📊 الإحصائيات
- عرض إجمالي عدد المهام
- عرض عدد المهام الجارية
- عرض عدد المهام المكتملة

### 💾 حفظ البيانات
- **Local Storage** - جميع البيانات تُحفظ محلياً في المتصفح
- تظل المهام محفوظة حتى بعد إغلاق المتصفح
- لا حاجة لخادم أو قاعدة بيانات

### 🎨 واجهة مستخدم
- تصميم حديث وجميل
- واجهة استجابية (Responsive)
- تجربة مستخدم سلسة
- دعم اللغة العربية

## 🚀 كيفية الاستخدام

### 1. فتح التطبيق
```
افتح ملف index.html في المتصفح
```

### 2. إضافة مهمة جديدة
- اكتب المهمة في حقل الإدخال
- اضغط على زر "إضافة" أو اضغط Enter

### 3. إدارة المهام
```
✔️  اضغط على الـ checkbox لتحديد المهمة كمكتملة
✏️  اضغط على أيقونة التعديل لتعديل المهمة
🗑️  اضغط على أيقونة الحذف لحذف المهمة
```

### 4. البحث والتصفية
- استخدم أزرار التصفية (جميع/جارية/مكتملة)
- استخدم حقل البحث للبحث عن مهمة معينة

### 5. إدارة المهام المكتملة
- اضغط على "حذف المهام المكتملة" لحذف جميع المهام المكتملة

## 📝 أمثلة الاستخدام

### حفظ البيانات
```javascript
// البيانات تُحفظ تلقائياً في Local Storage
function saveTodos() {
    localStorage.setItem('todoList', JSON.stringify(todos));
}
```

### تحميل البيانات
```javascript
// تُحمّل البيانات عند فتح الصفحة
function loadTodos() {
    const stored = localStorage.getItem('todoList');
    todos = stored ? JSON.parse(stored) : [];
}
```
